Introduction

This is the LibreForum administrator reference manual for LibreForum version 5.2.x and up. It is not intended for use with older versions of LibreForum, although a lot of information will apply.

Please keep in mind that this manual is neither complete, nor final. If you have any remarks about it, please let us know in the development forum on our website. With your contribution, we hope to make this manual a useful tool for LibreForum users in understanding and working with our software.

The LibreForum development team
